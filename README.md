# لوحة المجتازات

تطبيق ويب (Python / Flask) يحوّل قائمة أسماء + صورة خلفية إلى لوحات جاهزة.

## التشغيل
```bash
pip install -r requirements.txt
python app.py
```
ثم افتح http://127.0.0.1:5000

أو بـ Docker (يضمن أفضل جودة للنص العربي):
```bash
docker build -t board . && docker run -p 8000:8000 board
```
للنشر على استضافة: الأمر `gunicorn -w 2 -t 120 app:app` (أو استخدم Dockerfile).

## ماذا يفعل تلقائيًا
- **تنظيف الإدخال**: يحذف الإيموجي والترقيم ورموز `*` وعلامات الاتجاه، ويتجاهل أسطر العناوين، ويكتشف التكرار — **دون تغيير أي حرف في الاسم**.
- **التقسيم**: يوزّع الأسماء بالتساوي على لوحات (الافتراضي 34 اسمًا كحد أقصى)، والترقيم متصل عبر اللوحات.
- **التخطيط**: يختار عدد الأعمدة وحجم الخط تلقائيًا حسب عدد الأسماء وطول أطولها.
- **الخلفية**: يكتشف حدود الإطار، ويتجنب الزخارف (الورود) بمسح الصورة، ويعكس الألوان على الخلفيات الداكنة.
- **النص العربي**: محرك HarfBuzz/raqm إن توفر، وإلا `arabic-reshaper` + `python-bidi` تلقائيًا. الخط الذي لا يدعم رمزًا يُستبدل بخط احتياطي لهذا النص فقط مع تنبيه.
- **التصدير**: PNG لكل لوحة، أو ZIP، أو PDF.

## الخطوط
30 خطًا عربيًا (Cairo, Tajawal, Almarai, Amiri, Aref Ruqaa, Reem Kufi, …) من Google Fonts بترخيص OFL داخل مجلد `fonts/`.
لإضافة خط: ضع ملف `.ttf` في `fonts/` وأضف سطرًا في قائمة `FONTS` داخل `renderer.py`.
